What is MPC?

Multi-Party Computation (MPC) allows multiple parties to jointly compute a function over their inputs while keeping those inputs private. In the context of cryptography and blockchain, MPC enables distributed key generation and signing without any single party ever having access to the complete private key.

FROST Implementation

FROST (Flexible Round-Optimized Schnorr Threshold) is a state-of-the-art threshold signature scheme that enables multiple parties to collaboratively sign transactions. Our FROST implementations are optimized for hardware wallets, enabling distributed custody solutions with minimal communication overhead.

  • Two-round signing protocol for optimal efficiency
  • Proactive security with key resharing
  • Hardware wallet integration (Ledger, Keystone)
  • Baby Jubjub EdDSA support for ZK-friendly signatures
